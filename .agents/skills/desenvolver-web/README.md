# Replay Mod development skill

This is the full `desenvolver-web` package supplied for this project, with an English, Replay Mod-specific entry point in [SKILL.md](SKILL.md). It is intended for code agents editing this repository.

The original references, templates, icons, and helper scripts are preserved under `references/`, `assets/`, and `scripts/`. Those source-package files remain in Portuguese; use the English `SKILL.md` and repository `docs/` as the project contract. The scripts are optional and are not part of the Replay Mod runtime.

For any project task, start with the root [AGENTS.md](../../../AGENTS.md), then read this skill and the relevant English guides in [`docs/`](../../../docs/). Do not copy package examples into the product unless they fit the existing TypeScript, Luau, and Three.js architecture.
